# Task Structure Advisor —— 结构定义与标注规范 v0.1

状态：v0 冻结（与首版评测集同时定稿）；v0.1 为抽取层语义细化，
不改变捕获种类、等级公式与指标定义（见文末修订记录）。
标注来源声明：首版评测集为 agent 生成 + agent 自审的**暂定标注集**，
无人工复核，不构成人工金标准；人际标注一致性未测量。

## 1. 核心立场

捕获项只声称"文本里出现了什么"，不声称完整刻画任务。
- 标签描述**任务表述**的结构，不代表任务的真实解决难度。
- 没有明确表达的依赖，不得推断为"独立"。
- 无法可靠确认时记 unknown 或弃权；"未捕获到复杂结构"≠"简单"。

## 2. 捕获种类（8 种，固定）

| kind | 定义 | 正例 | 反例（不捕获） |
|---|---|---|---|
| goal | 显式交付义务：完不成即任务未做的动作 | "修复登录接口"、"补充测试" | 修饰成分："快速地"；背景叙述："上周修复了" |
| object | 操作对象/作用范围：反引号、路径、文件名、引号短语 | "`config.py`"、"src/app" | 泛指代词："这个系统"（仅当无任何锚点时按模糊处理，不捕获） |
| constraint | 完成任务时必须满足的附加条件 | "保持旧客户端兼容"、"不能修改公共接口" | 目标本身的名词重复："测试用例" |
| dependency | 文本明确表达的先后或产物依赖 | "先跑迁移再更新 API"、"A 依赖 B 的输出" | 推测的先后（未明说）；"随后"单独出现而无先项 |
| coordination | 文本明确表达的跨对象一致性要求 | "前后端错误码保持一致" | 单对象内部一致性 |
| condition | 影响执行路径的明确条件 | "如果超过 10GB 则分批" | 与目标动词同句且从属于该目标的普通状语 |
| unresolved | 文本明确的待调查/待决定事项 | "需要先弄清泄漏来源"、"待确认" | 模糊措辞（按弃权处理，不捕获） |
| acceptance | 文本明确的完成/验收条件 | "验收标准：全部用例通过" | 未写出的隐含验收 |

## 3. 歧义裁决规则（标注时按序执行）

1. **取消优先**：子句含取消动词（不需要/不必/取消/撤销/放弃/跳过…）且带元引用
   （要求/任务/计划/之前/上次…），或消息内存在"取消动词+元引用"的关联子句
   → 该内容不捕获。
2. **伪任务优先**：引导词（例如/比如/参考/背景/上次已经/for example…）、
   代码围栏、引用行内的"任务"不捕获。
3. **一子句一主捕获**：按 acceptance > unresolved > condition > dependency >
   coordination > constraint > goal 取优先级最高者。依赖从句内的目标动词
   不重复计数（被依赖引文包含）。
4. **承前并列**："支持导入以及导出"→ 两个 goal（"导出"承前借动词）。
   顿号名词列表不拆分（"把 A、B、C 改成 X"是一个 goal + N object）。
5. **复述合并**：同一要求的重复叙述（同义改写/子串复述）计 1，不按句数累加。
6. **依赖端点不明**：显式顺序存在但端点不可机械定位 → 计 dependency 1 次，
   同时记 unknowns=["dependency"]；不得推断两端"独立/可并行"。
7. **先…再… 跨子句**：合并为一个 dependency 捕获（引文含两段），
   内部义务不再单独计 goal（避免重复计数；此为 v0 的已知保守偏差）。

## 4. 等级定义（透明阈值 v0；阈值是待验证启发式）

结构向量：goals / constraints / explicit_dependencies / coordinations /
conditions_unresolved / objects（全部为去重后计数）。

- **high（结构复杂）**：goals ≥ 3，或 (constraints+deps+coordinations) ≥ 3，
  或 deps ≥ 2。
- **low（表述简单）**：goals = 1 且 (constraints+deps+coordinations) = 0。
- **medium**：介于两者（goals ≥ 2，或负担 ≥ 1）。
- **unknown（信息不足/弃权）**：截断输入；未捕获到显式义务；仅捕获到
  condition/acceptance/object 而无义务；目标模糊且无对象锚点。
  unknown 不等于简单，且永不作为"放行"依据。

等级标签描述表述负担，**不代表**真实耗时/知识难度/并行安全性。

## 5. 建议分型（与等级分离）

| advice | 触发（v0） | 提醒措辞要点 |
|---|---|---|
| split_by_goal | high 且 goals≥3 且 deps=0 | 按交付义务分批；是否拆解由主模型决定 |
| phased_with_integration | high 且 deps≥2 | 分阶段+最后整体核验；明示"不代表可并行" |
| coordination_caution | 其他 high；或 medium 且 coordinations≥2 | 收尾前逐项对照 |
| clarify_scope | abstain 且文本有任务意图标记 | 先明确范围与完成条件 |

无建议（None）是常态输出；提醒每任务版本默认至多 1 次；措辞禁止"必须/请务必"。

## 6. 评测指标

- 捕获 P/R/F1（按 kind；匹配 = gold quote 与预测 quote 的字符 bigram
  Jaccard ≥ 0.5 且 kind 一致）。
- 伪任务家族误捕获率（FP/text）；取消家族抑制正确率。
- 弃权正确率（gold abstain ↔ 预测 unknown；非 abstain 样本不得弃权）。
- 等级一致率（level_hint ↔ 预测 level；unknown 仅可与 unknown 一致）。
- 改写稳定率：paraphrase_pairs 两翼的向量完全相等比例。
- 复述不敏感率：restatement_dup 的 goals 计数 = gold 计数比例。

## 修订记录

### v0.1（2026-09-24）—— 抽取层"窄语义"三维度细化

实现现有条目的判定细节，不新增/修改捕获种类、优先级或等级公式：

1. **过去叙述判定**（细化 §3.2 伪任务）：过去时间词（上周/去年/当时…）、
   已知动词+过（经历体）、英文过去被动（was V-ed）→ 叙述而非请求；
   子句带请求标记（请/麻烦/please…）时翻转。
   注意"之前"不在时间词表内——它多表先后顺序（"迁移之前先备份"）。
2. **语境条件化触发**（细化 §3.2/§2）：①"当"必须是"当…时"框架且排除
   当时/当初/当务；②顺便/顺带为语气降调，不再否决带动词的内容子句；
   ③"依赖"后接清单/项/库/包/模块/关系时按复合名词处理，不触发依赖。
3. **取消语境细化**（细化 §3.1）：取消标记分两类——否定 modal
   （不需要/无需/不再…）出现即否定整句；及物取消动词（取消/撤销/作废…
   ）须带元引用或与元引用子句相邻（裸取消命令回指前句话题）。

已知有意不修："统一改成"的多义（协调 vs 义务）在 gold 中自相矛盾
（co_063 vs ro_107），留待 SLM 后端或规范 v1 裁决。

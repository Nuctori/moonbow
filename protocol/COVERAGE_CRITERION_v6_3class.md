# 证据强度判据 v6（三值：STRONG / MEDIUM / NONE）2026-09-18

> **本版替代 v5b/v5c。** 降为三值的依据是 FINDINGS §249–§250 的实测证伪，
> 不是偏好变更。

## 一、为什么必须降为三值（证伪链条）

v5b（§244 冻结版）是**四值**：STRONG / MEDIUM / **WEAK** / NONE。
四值成立的前提是「四档各自有独立可标注的证据」。该前提被三项实测证伪：

| 证据 | 内容 |
|---|---|
| §249 | 三批标注在「无产物 token」这一机械可判的桶上给出三套不同映射；漂移 **91/1138 = 8.0%** |
| §250 | 剔除漂移后 **WEAK 仅存活 27 条，且全部来自单一批次（b2）** |
| §252 复核 | 存活 27 条的 `tokens` 字段值是 `process-description` / `analysis-no-locator` / `process-name-only` —— **一个标注员的私有词汇表**，不是共享的档位定义 |

**⇒ WEAK 档没有跨批证据，其"定义"只存在于单个标注员的脑袋里。**
四值在数据上不成立，有效刻度为三值。

## 二、三值判据（机械可判，消除主观）

```
判定顺序（必须按序执行）：

  第 1 步（机械闸，无主观）
    work_log 有无任何【产物型 token】？
      ├─ 无  ⇒ NONE        ← 唯一门槛，机械可判
      └─ 有  ⇒ 进第 2 步

  第 2 步（按 token 类别定档）
      commit hash / 测试数字 / 构建成功 / 部署成功
          ⇒ STRONG
      动作词 + 指名文件/符号 / 具体行号 / 符号名（含"已落地到 X""已改成 Y"）
          ⇒ MEDIUM
```

**已删除的档位**：WEAK（"仅过程/机制描述，无指名对象"）。
原 WEAK 的语义**并入 MEDIUM**，理由：
WEAK 原定义要求判"有无指名对象"，这需要读者判断"这算不算定位"——
正是 §243–§244 已证明**无法跨标注员稳定**的那类判断。
并入 MEDIUM 后，第 2 步只剩 token 类别匹配，**全机械可判**。

**关键裁定（沿用 v5b）**：只要出现「动作词 + 指名文件/符号」，一律 MEDIUM。
「指名到具体文件」本身是可核验线索，区别于纯口头声明。

## 三、为什么并入 MEDIUM 而非 NONE

`NONE` 的语义是「未回答」。原 WEAK 的样本（如"这些问题的回归风险如何"）
是**已回答但无定位**，不是未回答。并入 NONE 会破坏 NONE 的机械门槛
（§249 已证该门槛是唯一稳定的档位边界）。故并入 MEDIUM。

## 四、v5b 四条界的去向

v5b 的四值 = 三条界。降三值后：

| 原界 | 处置 | 依据 |
|---|---|---|
| STRONG ↔ MEDIUM | **保留** | 两侧均有跨批证据（b1/b2/b3 都出 STRONG 与 MEDIUM） |
| MEDIUM ↔ WEAK | **取消**（WEAK 并入 MEDIUM） | WEAK 无跨批证据（§250） |
| WEAK ↔ NONE | **取消**（同上） | 同上 |
| MEDIUM ↔ NONE | **保留**（升为硬闸） | §241 实测：该界是反向率唯一来源，v5b 用硬裁定压到 0% |
| STRONG ↔ NONE | 由传递性覆盖 | — |

**⇒ 三值 = 两条界，两条界都有跨批证据 + 机械闸支撑。**

## 五、验收（预注册）

口径按 `MULTI_METRIC_ACCEPTANCE.md` v2 执行（含口径准入检验）。
反向率门槛按 `REVERSE_GATE_v2.md` 执行（三闸）。

| 指标 | 门槛 |
|---|---|
| exact 相对随机超额 | > 0 |
| within-1（主口径） | ≥ 0.95 |
| Spearman 序相关 | > 0.5 |
| 反向率（校正门） | 三闸同过 |

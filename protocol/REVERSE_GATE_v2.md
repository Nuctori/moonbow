# 反向率门槛 v2（偏斜校正版）

> 替代 §242 原门槛「反向率 ≤2%」。原门槛的失效已被实测证实（§248）：
> 72% MEDIUM 偏斜下，**全输出 MEDIUM 的 trivial 预测反向率 = 0.000**，恒过。

## 为什么必须校正

原门槛隐含假设"反向率能区分好坏预测器"。该假设在类别严重不平衡时不成立：
反向（差≥2 档）需要预测器同时**输出低档位**且**输出错误**。
一个从不敢输出低档位的预测器（trivial）反向率天然为 0，
而它显然没有任何能力。**门槛被平凡解放过。**

## 校正门槛（三闸，须同时通过）

```
前提定义
  trivial 预测 T = 训练/评估集中 gold 的多数类
  困难子集 H = { i : gold_i ≠ T }

G1  模型在 H 上的反向率  <  trivial 在 H 上的反向率
G2  模型在 H 上的反向率  ≤  2%
G3  max over g of (该 gold 层的反向率)  ≤  5%
    且报出各层的 Wilson 单侧 95% 上界（小层不用点估计）
```

**G1 的推导**：trivial 在**全体**上反向率恒为 0（因其只输出一个档位，
与任何 gold 差 ≤1 档），故全体口径下不可比。换到困难子集后
trivial 会产生真实的 ≥2 档错误，比较才有意义。

## 实测（`maps/reverse_gate_result.json`）

| 对象 | G1 | G2 | G3 | 全体反向率 |
|---|---|---|---|---|
| 287M 模型 | FAIL (0.0161 vs 0.0000) | PASS | PASS (0.0172) | 0.0048 |
| trivial（全 MEDIUM） | FAIL (0.0000 vs 0.0000) | PASS | PASS (0.0000) | 0.0000 |
| 随机打乱 | **FAIL** | **FAIL** (0.0323) | **FAIL** (0.2500) | 0.0096 |

**区分力已恢复**：随机三闸全挂。

## ⚠️ 门槛本身的诚实局限（必须随门槛一起引用）

G1 在当前样本量下**不可判定**：困难子集 n=62，trivial 0/62 的 Wilson 上界 = **0.0583**，
模型 1/62 = 0.0161 **落在其内**。**1 例差异不是证据。**

**⇒ 更深的问题：反向率在现有输出分布下不是区分轴。**
模型几乎不输出 WEAK/NONE（pred: NONE=1, WEAK=17），
而不输出低档位者天然不反向。继续围绕反向率设门槛属于**优化退化指标**。

**建议的替代主轴**：`adjacent`（≤1 档）。它是唯一同时满足
(a) 与随机基线可比、(b) 对输出分布退化敏感、(c) 直接反映"分档是否有意义"的指标。
实测 adjacent = 0.215 vs 随机基线 0.420（**低于随机**）。

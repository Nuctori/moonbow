# 门禁报告 v2（修订案 v1.1 ge3 校准结果）

日期：2026-10-03 晨。依据：方案修订案 v1.1（登记于 ge3 数据采集前）。

## 校准数据（gemini-3.5-flash-lite，control，各 2 run）

| 任务 | 设计杠杆 | 结果 | 轮次均值 |
|---|---|---|---|
| g1_rates_interact | 浮点累加顺序×舍入策略 + 闭包晚绑定，4 文件 | **3/3 全过 ×2** | 16 |
| g2_search_locate | 模块级生成器耗尽 + 贪婪正则 + 大小写排序，5 文件含诱饵 | **4/4 全过 ×2** | 16.5 |
| g3_rounding_policy | 银行家舍入 vs HALF_UP 政策（naive round 挂 2/4） | **3/3 全过 ×2** | 6 |

对照旧任务集轮次（8-11）：**难度提升有效果但未越过失败线**——gemini 以
更多迭代轮次补偿（14-19 轮），完成率仍 100%。

## 判定（按修订案预登记条款）

全部任务触顶 → **终止，出具本报告，主实验不启动**。
gemini-3.5-flash-lite 在本任务类上的能力上限远高于
"pytest 单文件/多文件 bug 修复"任务族的设计空间。

## 结论（沿用方案 §6 措辞纪律）

- L4 uplift：**不可测**（免费渠道唯一存活模型触顶；备用通道全部不可用）。
- L1 无害性：**达标并扩样**（+6 run，累计 40 run 零误投递）。
- 观察性发现（非结论）：轮次显著上升说明任务难度杠杆有效作用于工作量，
  但完成率对此模型不敏感——若换 mimo（历史 40% 基线）同卷，
  这套 ge3 任务集正是落带候选。
